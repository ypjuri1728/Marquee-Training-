# 🛒 Flipkart — HTML & CSS Practice

A simple Flipkart-inspired webpage created using **HTML and CSS** as part of my frontend development practice.

This project focuses on practicing basic HTML structure and CSS styling concepts.

---

## 📁 Project Structure

- `index.html` — Main webpage structure
- `style.css` — Styling and layout
- `images/` — Images used in the webpage

---

## ✨ Features

- Header section with Flipkart-style logo
- Travel section
- Location section
- Search bar and search button
- Product/recommendation section
- Product images
- Footer section
- About and Help sections
- Copyright section

---

## 🛠️ Built With

- HTML
- CSS

---

## 📚 Concepts Practiced

- HTML elements and structure
- `<div>` elements
- Headings and paragraphs
- Images
- CSS selectors
- Box model
- `margin` and `padding`
- `display: flex`
- `display: inline-block`
- `gap`
- `width` and `height`
- Background colors
- Borders
- Border radius
- Text styling
- Image sizing
- Footer layout

---

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any browser.

---

## 🎯 Purpose

This project was created to practice and strengthen my **HTML and CSS fundamentals** by recreating a simple e-commerce webpage layout.
