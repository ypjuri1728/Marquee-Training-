# 🎨 Whiteboard — HTML, CSS & JavaScript

A simple interactive **Whiteboard application** built using HTML, CSS, and JavaScript.

This project allows users to draw on a canvas, clear the board, change the brush color, and change the background color.

---

## ✨ Features

- Draw on the canvas using the mouse
- Clear the entire board
- Change brush color using right-click
- Change canvas background color using double-click
- Smooth rounded brush strokes
- Mouse-based drawing interaction
- Simple and clean interface

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- HTML Canvas API
