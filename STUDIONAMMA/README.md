# 🎨 StudioNamma

A creative studio website built using HTML, CSS, and JavaScript.

## 🚀 About the Project

StudioNamma is a modern creative studio website focused on bold typography, interactive video sections, hover effects, smooth transitions, and scroll-based animations.
---
## ⚡ INTERACTION

The website uses simple frontend technologies to create dynamic interactions:

- Hover-based video reveals
- Blur and focus effects
- Opacity transitions
- Scroll-based typography scaling
- HTML5 video backgrounds
- JavaScript DOM interactions
- CSS positioning and transformations
